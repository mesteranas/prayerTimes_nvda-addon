Gebetszeiten

Eine Erweiterung für den NVDA-Bildschirmleser, mit der Sie schnell die aktuellen Gebetszeiten für Muslime an jedem Ort der Erde abrufen können.

Installation

Sie können diese Erweiterung direkt aus dem NVDA Add-on Store installieren oder von der Releases-Seite herunterladen.

Verwendung

Standardmäßig erkennt die Erweiterung Ihren Standort automatisch anhand Ihrer IP-Adresse. Bitte beachten Sie, dass diese Methode in einigen Fällen ungenau sein kann.

Um eine höhere Genauigkeit zu erreichen, können Sie die automatische Erkennung in den Einstellungen deaktivieren und Ihren aktuellen Breitengrad (Latitude) und Längengrad (Longitude) manuell eingeben. Sie können diese präzisen Koordinaten ganz einfach mithilfe einer GPS-basierten Standort-App auf Ihrem Mobiltelefon ermitteln.

Hauptfunktionen & Tastenkombinationen

  • Gebetszeiten anzeigen: Drücken Sie NVDA+ALT+P, um die heutigen Gebetszeiten in einem gut lesbaren Textfeld anzuzeigen.
  • Nächstes Gebet anzeigen: Drücken Sie NVDA+Umschalt+P, um die Zeit des bevorstehenden Gebets zu überprüfen.

Hinweis: Alle diese Tastenkombinationen können über den NVDA-Dialog „Eingaben“ angepasst werden.

Zwischenspeicherung (Caching)

Um sofortige Ergebnisse zu liefern, speichert die Erweiterung die Gebetszeiten beim ersten Drücken einer Tastenkombination während einer NVDA-Sitzung zwischen. Dieser Zwischenspeicher wird automatisch gelöscht, wenn Sie NVDA neu starten oder im Einstellungsdialog auf die Schaltfläche OK klicken.

Unterstützte Sprachen

Die Erweiterung unterstützt derzeit die folgenden Sprachen:

  • Englisch
  • Deutsch
  • Türkisch

Hinweis: Der Entwickler pflegt die arabischen, englischen und deutschen Übersetzungen aktiv.
