# Prayer Times



An NVDA screen reader add-on that allows you to quickly get the current prayer times for Muslims anywhere on Earth.



## Installation



You can install this add-on directly from the NVDA Add-on Store, or you can download it [from the releases page](https://github.com/mesteranas/prayerTimes_nvda-addon/releases).



## Usage



By default, the add-on automatically detects your location using your IP address. Please note that this method may be inaccurate in some cases.



To achieve higher accuracy, you can disable automatic detection in the settings and manually enter your current latitude and longitude. You can easily find these precise coordinates using a GPS-based location app on your mobile phone.



### Key Features & Shortcuts



* **View Prayer Times:** Press **NVDA+ALT+P** to display today's prayer times inside a readable text field.

* **View Next Prayer:** Press **NVDA+Shift+P** to check the upcoming prayer time.



> **Note:** All of these shortcuts can be customized via the NVDA Input Gestures dialog.



### Caching



To provide instant results, the add-on caches the prayer times upon your first shortcut press during an NVDA session. This cache is automatically cleared when you restart NVDA or when you press the **OK** button in the settings dialog.

The add-on currently supports the following languages:

* Turkish
